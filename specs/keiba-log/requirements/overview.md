# プロジェクト概要: keiba-log

| 項目 | 内容 |
|---|---|
| 機能名 | `keiba-log` |
| 担当 | requirements-analyst |

## 目的

競馬の馬券とその収支を記録し、ユーザー自身の生涯収支を把握できるようにする Web アプリケーション。ユーザーは購入した馬券を登録するだけで、これまでの累計の収支額と回収率をいつでも確認できる状態になることをゴールとする。

## MVP機能

| # | 領域 | 内容 |
|---|---|---|
| 1 | ユーザー登録・認証 | ユーザーが自分のアカウントを作成し、送信された確認メールに記載された確認コードを画面で入力してメールアドレスを確認し、アカウントを有効化する。ログイン後は自分のデータのみを扱い、自分のアカウントを削除することもできる。 |
| 2 | 馬券登録 | 日付・競馬場・レース・馬券の内容を入力して馬券を登録する。詳細が不明な場合は、日付と競馬場のみを必須とし、複数レースをまとめた購入額と払い戻しだけの収支としても登録できる。 |
| 3 | 馬券の編集・削除 | 登録済みの馬券の内容を修正したり、不要な記録を削除する。 |
| 4 | 馬券一覧 | 登録した馬券を日付の新しい順に一覧で確認する。 |
| 5 | 生涯収支サマリー | ホーム画面に、登録済みの全馬券から算出した生涯の収支額と回収率を表示する。 |
| 6 | 直近の馬券記録 | ホーム画面に、直近5件の馬券記録をリストで表示する。 |

## 前提

- 個人利用のみを対象とし、各ユーザーは自分の馬券・収支だけを閲覧する。他ユーザーへの共有・公開・ランキングは行わない。
- 認証方式はメールアドレスとパスワードによる認証のみとし、ソーシャルログインは対象外。
- レースおよび馬券の情報はすべてユーザーの手入力とし、外部データとの連携は行わない。
- 集計は生涯累計のみとし、年別・月別などの期間別集計は対象外。
- 一覧は日付の新しい順の並び順のみで、絞り込み・検索は対象外。
- 提供形態はスマートフォンと PC の双方の画面サイズに対応するレスポンシブ Web アプリのみ。ネイティブアプリ・PWA・オフライン利用は対象外。
