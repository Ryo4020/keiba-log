# REQ-TICKET-002: 簡易記録の登録

| 項目 | 内容 |
|---|---|
| 要件ID | `REQ-TICKET-002` |
| 担当 | user-story-analyst |

## ユーザーストーリー

馬券の詳細が分からないときに、日付・競馬場と購入額・払戻額だけで収支を記録したい。

## 受け入れ基準

| # | EARS | 内容 |
|---|---|---|
| 1 | WHEN | WHEN ユーザーが簡易記録の登録を開始する THEN システムは日付・競馬場・購入額・払戻額を入力できる状態にしなければならない。 |
| 2 | ユビキタス | システムは競馬場の入力を、`business-rules.md` に定義された競馬場のマスタデータからの選択式にしなければならない。 |
| 3 | ユビキタス | システムは簡易記録に買い目を持たせてはならない。 |
| 4 | ユビキタス | システムは簡易記録に結果状態を持たせてはならない。 |
| 5 | WHEN | WHEN 正常な入力で登録を実行する THEN システムは簡易記録をログイン中のユーザー自身の馬券記録として保存しなければならない。 |
| 6 | WHEN | WHEN 簡易記録を保存する THEN システムは記録種別を簡易記録として保存しなければならない。 |
| 7 | IF | IF 入力値が不正である THEN システムは登録を実行せず、不正な項目を示さなければならない。 |

## UI設計上の留意点

- レース記録と簡易記録のどちらを登録しているかが、入力中に判別できること。
