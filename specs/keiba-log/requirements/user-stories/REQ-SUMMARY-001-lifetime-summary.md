# REQ-SUMMARY-001: 生涯収支サマリー表示

| 項目 | 内容 |
|---|---|
| 要件ID | `REQ-SUMMARY-001` |
| 担当 | user-story-analyst |

## ユーザーストーリー

ホーム画面で、これまでに登録した全馬券記録から算出した生涯の収支額と回収率を確認したい。

## 受け入れ基準

| # | EARS | 内容 |
|---|---|---|
| 1 | WHEN | WHEN ユーザーがホーム画面を表示する THEN システムは収支サマリーに生涯の収支額を表示しなければならない。 |
| 2 | WHEN | WHEN ユーザーがホーム画面を表示する THEN システムは収支サマリーに生涯の回収率を、`business-rules.md` の回収率の表記の精度（小数第2位を四捨五入した小数第1位まで）に従って表示しなければならない。 |
| 3 | ユビキタス | システムは収支サマリーの集計対象を、ログイン中のユーザー自身が登録した全馬券記録としなければならない。 |
| 4 | ユビキタス | システムは収支額と回収率を、`business-rules.md` の収支額・回収率の算出ルールに従って算出しなければならない。 |
| 5 | IF | IF `business-rules.md` の算出ルールで回収率が算出できない条件に該当する THEN システムは回収率の値を表示せず、算出できない状態であることを示さなければならない。 |
| 6 | ユビキタス | システムは集計期間の指定および絞り込みの操作を提供してはならない。 |
| 7 | WHEN | WHEN 馬券記録が登録・変更・削除された後にホーム画面が表示される THEN システムは反映後の収支額と回収率を表示しなければならない。 |
| 8 | IF | IF 集計対象の馬券記録が0件である THEN システムは空状態であることを示す表示をしなければならない。 |

## UI設計上の留意点

- 収支額が利益・損失・均衡のいずれかを、値の符号以外の手段でも読み取れること。判定は収支額の正負で行い、丸めた回収率（例: 100.0％）では行わないこと。
