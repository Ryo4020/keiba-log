# REQ-TICKET-004: 馬券記録の削除

| 項目 | 内容 |
|---|---|
| 要件ID | `REQ-TICKET-004` |
| 担当 | user-story-analyst |

## ユーザーストーリー

不要になった馬券記録を削除したい。

## 受け入れ基準

| # | EARS | 内容 |
|---|---|---|
| 1 | WHEN | WHEN ユーザーが馬券記録の削除を実行しようとする THEN システムは削除の確認操作を求めなければならない。 |
| 2 | IF | IF ユーザーが確認操作で削除を取りやめる THEN システムは削除を実行してはならない。 |
| 3 | WHEN | WHEN ユーザーが確認操作で削除を承認する THEN システムは対象の馬券記録を削除しなければならない。 |
| 4 | WHEN | WHEN レース記録を削除する THEN システムは当該レース記録に属する買い目と買い目の集合も削除しなければならない。 |
| 5 | ユビキタス | システムは削除した馬券記録を復元させてはならない。 |
| 6 | IF | IF 対象がログイン中のユーザー自身の馬券記録でない THEN システムはその馬券記録を削除させてはならない。 |

## UI設計上の留意点

- 削除が取り消せないことが、確認操作の時点で分かること。
