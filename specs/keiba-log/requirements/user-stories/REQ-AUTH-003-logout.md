# REQ-AUTH-003: ログアウト

| 項目 | 内容 |
|---|---|
| 要件ID | `REQ-AUTH-003` |
| 担当 | user-story-analyst |

## ユーザーストーリー

利用を終えるときに自分のデータを他人に見られないようにするため、認証状態を終了したい。

## 受け入れ基準

| # | EARS | 内容 |
|---|---|---|
| 1 | WHILE | WHILE ユーザーが認証状態である システムはログアウトを実行する手段を提供しなければならない。 |
| 2 | WHEN | WHEN ユーザーがログアウトを実行する THEN システムはそのユーザーの認証状態を終了しなければならない。 |
| 3 | WHEN | WHEN 認証状態を終了する THEN システムはログイン画面を表示しなければならない。 |
