# REQ-TICKET-006: 直近記録リスト表示

| 項目 | 内容 |
|---|---|
| 要件ID | `REQ-TICKET-006` |
| 担当 | user-story-analyst |

## ユーザーストーリー

ホーム画面で直近の馬券記録をすぐに確認し、そこから記録を開きたい。

## 受け入れ基準

| # | EARS | 内容 |
|---|---|---|
| 1 | WHEN | WHEN ユーザーがホーム画面を表示する THEN システムはログイン中のユーザー自身の馬券記録のうち、日付の新しい順で先頭5件を直近記録リストに表示しなければならない。 |
| 2 | IF | IF 表示対象の馬券記録が5件未満である THEN システムは存在する件数のみを表示しなければならない。 |
| 3 | ユビキタス | システムは直近記録リストにページングを設けてはならない。 |
| 4 | ユビキタス | システムは直近記録リストの各行に、記録種別を判別できる情報を表示しなければならない。 |
| 5 | WHEN | WHEN ユーザーが直近記録リストの行を選択する THEN システムは当該馬券記録の編集画面に遷移しなければならない。 |
| 6 | ユビキタス | システムは直近記録リストに馬券記録の削除を開始する操作を提供してはならない。 |
| 7 | ユビキタス | システムは直近記録リストに馬券記録一覧（`REQ-TICKET-005`）へ遷移する操作を提供しなければならない。 |
| 8 | IF | IF 表示対象の馬券記録が0件である THEN システムは空状態であることを示す表示をしなければならない。 |

## UI設計上の留意点

- 行を選択すると編集画面に遷移するため、選択できる行であることが分かること。
- 削除操作は一覧側にのみ存在するため、直近記録リストの行に削除の操作を置かないこと。
