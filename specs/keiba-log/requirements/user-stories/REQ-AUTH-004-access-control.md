# REQ-AUTH-004: アクセス制御

| 項目 | 内容 |
|---|---|
| 要件ID | `REQ-AUTH-004` |
| 担当 | user-story-analyst |

## ユーザーストーリー

自分の馬券記録を自分だけが扱える状態にするため、未認証でのアクセスを制限し、参照・操作の対象を自分のデータに限定したい。

## 受け入れ基準

| # | EARS | 内容 |
|---|---|---|
| 1 | ユビキタス | システムはホーム画面・馬券記録の一覧・馬券記録の登録・馬券記録の編集・馬券記録の削除・ログイン中の画面操作によるパスワードの変更を、ログインが必要な機能として扱わなければならない。 |
| 2 | ユビキタス | システムはログイン画面・アカウント登録・確認コードの入力によるメールアドレス確認・確認コードの再送・パスワード再設定の申請・再設定コードと新しいパスワードの入力によるパスワードの再設定を、未認証で利用できる機能として扱わなければならない。 |
| 3 | IF | IF 未認証の状態でログインが必要な機能へアクセスする THEN システムはその機能を利用させず、ログイン画面へ誘導しなければならない。 |
| 4 | IF | IF 認証状態が失効している THEN システムはログインが必要な機能を利用させず、ログイン画面へ誘導しなければならない。 |
| 5 | WHILE | WHILE ユーザーが認証状態である システムは参照・操作の対象をそのユーザー自身のデータに限定しなければならない。 |
| 6 | IF | IF 認証状態のユーザーが自分以外のユーザーの馬券記録を参照または操作しようとする THEN システムはその要求を拒否しなければならない。 |
