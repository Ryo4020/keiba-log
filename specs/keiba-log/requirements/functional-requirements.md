# 機能要件一覧: keiba-log

| 項目 | 内容 |
|---|---|
| 機能名 | `keiba-log` |
| 担当 | functional-analyst |
| インプット | `requirements/overview.md` |

## 用語定義

アプリ特有の機能に関する用語を定義する。

| 用語 | 定義 |
|---|---|
| 馬券記録 | ユーザーが登録する1件のデータ単位。一覧・編集・削除・集計の対象となる最上位の単位 |
| 記録種別 | 馬券記録が「レース記録」「簡易記録」のいずれであるかを表す区分 |
| レース記録 | レース単位で馬券の内容を入力する記録種別。1件のレース記録は1件以上の買い目を持つ |
| 買い目 | 券種・対象・購入額を一つにまとめた単位。対象とは購入した番号（馬番または枠番）の組み合わせを指す。買い目は払戻額と結果状態も持つ |
| 簡易記録 | 日付と競馬場のみを必須とし、複数レース分の購入額・払戻額をまとめて入力する記録種別。買い目は持たない |
| 生涯集計 | ユーザーが登録した全馬券記録を対象とする集計範囲。期間の指定は行わない |
| 収支サマリー | 生涯集計の結果（収支額・回収率）をまとめて表示する画面上の領域 |
| 直近記録リスト | ホーム画面に、日付の新しい順で先頭5件の馬券記録を表示する画面上の領域 |
| ホーム画面 | ログイン後に最初に表示され、収支サマリーと直近記録リストを掲載する画面 |
| 空状態 | 馬券記録が0件のときに一覧・収支サマリーが取る表示状態 |
| 自分のデータ | ログイン中のユーザー自身が登録した馬券記録。他ユーザーの記録は含まない |
| 未確認アカウント | アカウント登録直後で、メールアドレスの確認が完了していない状態のアカウント |
| 有効化済みアカウント | メールアドレスの確認が完了し、利用可能な状態になったアカウント |
| 確認メール | アカウント登録時と確認コードの再送時に登録アドレス宛へ送信される、確認コードを含むメール |
| 確認コード | 確認メールに記載され、メールアドレスを確認するためにアプリの画面で入力するコード |
| パスワード再設定メール | パスワード再設定の申請時に登録アドレス宛へ送信される、再設定コードを含むメール。確認メールとは別種のメール |
| 再設定コード | パスワード再設定メールに記載され、新しいパスワードとともにアプリの画面で入力して新しいパスワードを設定するためのコード |

## 要件ID体系

要件IDは `REQ-<領域>-<連番>` の形式で付与する。

| 領域コード | 対象範囲 | 要件数 |
|---|---|---|
| `AUTH` | ユーザー登録・メールアドレス確認・認証・アクセス制御・パスワード再設定・アカウント削除 | 8 |
| `TICKET` | 馬券記録の登録・編集・削除・表示 | 6 |
| `SUMMARY` | 生涯収支の集計と表示 | 1 |

**合計: 15要件**

## 機能一覧

### A. ユーザー登録・認証（REQ-AUTH）

| 要件ID | 機能名 | 概要 |
|---|---|---|
| `REQ-AUTH-001` | アカウント登録 | ユーザーが認証情報を入力して自分のアカウントを新規作成する。 |
| `REQ-AUTH-002` | ログイン | 登録済みの認証情報でログインし、自分のデータを扱える状態にする。 |
| `REQ-AUTH-003` | ログアウト | ログイン中のユーザーが認証状態を終了する。 |
| `REQ-AUTH-004` | アクセス制御 | 未認証状態での画面・データへのアクセスを制限し、参照・操作の対象を自分のデータに限定する。 |
| `REQ-AUTH-005` | アカウント削除 | ログイン中のユーザーが自分のアカウントを削除する。 |
| `REQ-AUTH-006` | メールアドレス確認 | 確認メールに記載された確認コードをアプリの画面で入力してメールアドレスを確認し、未確認アカウントを有効化する。確認コードを受け取り直すための確認コードの再送を含む。 |
| `REQ-AUTH-007` | パスワード再設定の申請 | パスワードを忘れたユーザーがメールアドレスを入力して再設定を申請し、パスワード再設定メールを受け取る。 |
| `REQ-AUTH-008` | パスワードの変更 | パスワード再設定メールに記載された再設定コードを画面で入力して新しいパスワードを設定する場合と、ログイン中に現在のパスワードを確認して画面上で新しいパスワードに変更する場合の両方で、新しいパスワードを入力して設定する。 |

### B. 馬券記録（REQ-TICKET）

| 要件ID | 機能名 | 概要 |
|---|---|---|
| `REQ-TICKET-001` | レース記録の登録 | 日付・競馬場・レースを入力し、同じレースに対して買い目を1件以上入力して馬券記録を登録する。 |
| `REQ-TICKET-002` | 簡易記録の登録 | 日付・競馬場と、複数レース分をまとめた購入額・払戻額のみを入力して馬券記録を登録する。 |
| `REQ-TICKET-003` | 馬券記録の編集 | 登録済みの馬券記録の内容を呼び出して修正し、保存する。レース記録では買い目の追加・削除も行える。 |
| `REQ-TICKET-004` | 馬券記録の削除 | 不要になった馬券記録を削除する。 |
| `REQ-TICKET-005` | 馬券記録一覧 | 自分の馬券記録を日付の新しい順に一覧表示し、記録種別が分かる形で確認する。 |
| `REQ-TICKET-006` | 直近記録リスト表示 | ホーム画面で、自分の馬券記録のうち日付の新しい順で先頭5件をリスト表示する。 |

### C. 生涯収支サマリー（REQ-SUMMARY）

| 要件ID | 機能名 | 概要 |
|---|---|---|
| `REQ-SUMMARY-001` | 生涯収支サマリー表示 | ホーム画面で、自分の全馬券記録を対象とした生涯の収支額と回収率を表示する。 |
